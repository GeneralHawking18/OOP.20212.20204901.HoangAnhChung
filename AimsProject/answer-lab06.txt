- Observe what happens and explain it in detail:
	+ It is obviously Polymorphism. 
	That means that:
	In for-loop block:
		for (Media m: mediae) 
		System.out.println(m.toString()); \\ m is an object of Media. 
	The statement generalizes that an media object use its toString.
	But by Polymorphism, each object belonging to the its class will execute its toString.
	In particular, if the iterator 'm' point to an CD object, then m is downcasted into CD object.
	After running down into child class CD, then execute CD.toString().
